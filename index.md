# Mây Book

Mây Book is an EPUB reader for iPhone with an optional AI reading assistant that uses your own API key.

Mây Book là ứng dụng đọc sách EPUB cho iPhone, có trợ lý đọc AI tuỳ chọn dùng khoá API của chính bạn.
